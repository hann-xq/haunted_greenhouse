# The Enchanted Greenhouse

A small virtual world made in [Processing](https://processing.org/). You play a young wizard in
a greenhouse full of shy, magical plant-creatures. Your job is to collect every plant on a
random recipe card, but you have to stay quiet: if the room gets too loud, the plants get
startled and won't let you pick them.

Made for the Programming module of the Minor Creative Design & Technology at Saxion.

## How to play

1. The game opens on the help menu. Press **Resume** (or **×**) to start.
2. Look at the **recipe card** in the top-left. It lists which plants you need and how many.
3. Walk up to a plant. When you're close enough, three small leaves appear above it.
4. **Click the plant 3 times** to pick it. Each click fills in one leaf.
5. Picked plants sparkle, disappear, and grow back after a moment. Only plants that are still
   on your recipe count towards your basket.
6. **Stay quiet.** The game listens through your microphone. When the noise meter at the top
   goes past the line, all plants get startled (they bounce fast and show alarm marks), and
   clicks don't work until it has been quiet for a second. Clicks you already made are kept.
7. When every line on the recipe is ticked, you win. Press **Restart** for a new recipe.

There is no timer and no way to lose.

### Controls

| Action | Input |
|---|---|
| Walk | Arrow keys or W A S D |
| Pick a plant | Mouse click (3 times, standing close) |
| Switch character | 1 = Pip, 2 = Bram, 3 = Wren |
| Help menu | Click the **?** button (top-right) |
| Calm the plants | Be quiet (microphone) |

### Live weather

The greenhouse shows the real weather outside, fetched once when the game starts from the
[Open-Meteo](https://open-meteo.com/) API (free, no API key needed):

| Weather outside | What you see in the greenhouse |
|---|---|
| Night | The scene gets a dark blue tint |
| Cloudy | The scene gets greyer the more clouds there are |
| Fog | A pale haze |
| Rain, drizzle or showers | Rain streaks on the glass behind the plants |
| Thunderstorm | Rain plus a lightning flash now and then |

A small label in the top-right shows the city, the temperature and the weather. Without an
internet connection the game still works with clear daytime weather, and the label says
"Weather offline".

## Running it

1. Install [Processing 4](https://processing.org/download).
2. Install the **Sound** library: in Processing, go to
   *Sketch → Import Library → Manage Libraries*, search for **Sound** (by The Processing
   Foundation) and click *Install*.
3. Download or clone this repository. Keep the folder named `haunted_greenhouse`, because
   Processing needs the folder name to match the main file.
4. Open `haunted_greenhouse.pde` in Processing and press **Run**.

Notes:
- The game needs a **microphone**. On macOS, allow Processing to use the microphone the first
  time it asks. Without a microphone the game still runs; the plants just never get startled.
- The window opens a moment after you press Run, because the game first fetches the weather.

## Settings you can change

All settings are named constants at the top of their tab.

| Constant | Tab | What it does |
|---|---|---|
| `CITY_NAME`, `LATITUDE`, `LONGITUDE` | `Weather` | Which city's weather to show (default: Enschede). |
| `TEST_WEATHER_CODE` | `Weather` | Preview a weather look without waiting for it: `0` clear, `45` fog, `63` rain, `95` thunderstorm. `-1` uses the live weather. |
| `TEST_NIGHT` | `Weather` | Set to `true` to preview the night look. |

## Project structure

```
sketch_greenhouse/
├── sketch_greenhouse.pde   setup(), draw(), game states, input, microphone, loading images
├── Plant.pde               Plant class: bounce, startled state, clicks, collecting, respawning
├── Player.pde              Player class: walking on the floor, keyboard flags
├── Recipe.pde              Recipe class: random recipe, counting collected plants, recipe card
├── Button.pde              Button class: sprite buttons with a label and a click test
├── Hud.pde                 Noise meter, basket counter, weather label, help menu, win screen
├── Weather.pde             Fetching the weather from Open-Meteo and drawing the weather effects
└── data/
    ├── greenhouse_background.png
    ├── greenhouse_sprites/   the 3 characters and 4 plant species
    ├── ui/                   recipe card, panel, buttons, noise meter, basket, pips, tick
    └── fx/                   startle marks and collect sparkle
```
